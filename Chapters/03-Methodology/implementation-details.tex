\section{Implementation Details (RGSW/Library)}
\label{sec:impl:lib}
\begin{itemize}
    \item Provides an abstract interface called \texttt{ExtendedCryptoContext} which exposes RGSW functions (EncryptRGSW, EvalExternalProduct, EvalInternalProduct etc.)
    \item Two concrete implementations of the \texttt{ExtendedCryptoContext} interface based on:
    \begin{itemize}
        \item the BV (double decomposition) gadget
        \item the Hybrid approach (GHS in practice)
    \end{itemize} 
\end{itemize}
