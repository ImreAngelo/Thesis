\subsection{GHS/Hybrid}
\begin{itemize}
    \item Reuses OpenFHE internals, including Hybrid keyswitching settings
    \item Downsides: 
    \begin{itemize}
        \item Implementation-specific: parameters tied to keyswitching, can be a problem if a program uses both keyswitching and RGSW
        \item Internal product not really valid
        \item Security must be evaluated at ciphertext modulus $QP$
    \end{itemize}
\end{itemize}
