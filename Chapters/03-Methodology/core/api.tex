\section{Implementation Details of the Core Library}
\label{sec:impl:core}

\subsection{Architecture}
\begin{itemize}
    \item \corelib{} (directory \texttt{libs/core} of \cite{gitrepo}) extends OpenFHE's \texttt{CryptoContext} with an abstract interface \texttt{IExtendedContext} exposing the RGSW operations of \autoref{tab:main-functions}.
    % FLAG: earlier draft called the interface ``ExtendendedCryptoContext''; the type is IExtendedContext, handled via the alias ExtendedContext (a shared pointer).
    \item Interface/implementation separation: any number of concrete instantiations (one per gadget construction) implement the same interface; consuming code depends only on the interface, not on the instantiation.
    \item The interface mirrors OpenFHE's API and naming conventions (\texttt{Encrypt*}, \texttt{Eval*}); a user familiar with OpenFHE can adopt the library directly.
    \item Codebase layout (\texttt{libs} directory): \corelib{} (RGSW functionality), \serverlib{} and \clientlib{} (\gls{spar} server/client functions built on \corelib). Auxiliary directories: \texttt{benchmark} and \texttt{test} (see \autoref{sec:experimental-setup}), and \texttt{scripts} (Python; security/parameter estimation via the lattice estimator).
\end{itemize}

    \begin{tabular}{r|l}
        \Call{EncryptRGSW}{pk, pt}              & RGSW encryption of a plaintext \\
        \Call{MakePublicRGSW}{pk, pt}           & Noiseless (public) RGSW, $Z = 0$ \\
        \Call{EvalExternalProduct}{rlwe, rgsw}  & External product $\boxdot$ \\
        \Call{EvalInternalProduct}{lhs, rhs}    & Internal product $\boxtimes$ \\
        \Call{EvalAddRGSW}{lhs, rhs}            & Row-wise RGSW addition \\

        \Call{EvalMultRGSW}{rgsw, pt}           & RGSW--plaintext multiplication

\begin{itemize}
    \item RGSW data structure: a vector of RLWE ciphertexts --- the rows of $C = Z + \mu G$ \eqref{def:rgsw} --- each an ordinary OpenFHE ciphertext. The number of rows is determined by the gadget ($2k\ell$ for the BV instantiation below).
    \item \Call{MakePublicRGSW}{} outputs $\mu G$ exactly ($Z = 0$, i.e.\ $a = 0,\ \epsilon = 0$): not a ciphertext in the cryptographic sense but a plaintext carried in RGSW form, enabling products with true ciphertexts. Used for server-side constants in \autoref{sec:impl:spar}.
    \item Two concrete implementations are bundled. This chapter documents the canonical one, built on the layered RNS/digit gadget of \autoref{sec:gadget-decomposition} and referred to as the \emph{BV} instantiation; it is canonical because it matches how the external product is defined in the literature (via digit decomposition) \cite{cryptoeprint:2018/421, cryptoeprint:2025/860} and uses true \gls{rgsw} ciphertexts. The second implementation, based on modulus extension, is deferred to \autoref{chp:results}.
    % FLAG: previous draft cited the placeholder \cite{examples-of-this} and referenced sec:hybrid, which lives in the commented-out ghs-old.tex; both removed here.
\end{itemize}

\begin{remark}
    The implementations are coupled to OpenFHE's \texttt{CryptoContextBGVRNS}. Since OpenFHE exposes a unified interface for BGV and BFV, and the RGSW products are scheme-agnostic, extending the library to BFV would require little work.
\end{remark}
