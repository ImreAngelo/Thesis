
\section{Code Structure}
The source code is published in a git repository~\cite{gitrepo} as three C++ libraries under \texttt{libs/}, each a separate build target with its own public header directory. The \corelib{} library extends OpenFHE with \gls{rgsw} ciphertexts and related products. The \gls{spar} protocol is split into separate \clientlib{} and \serverlib{} libraries, so that client and server binaries can be compiled independently.

We highlight that the \corelib{} is entirely independent of \gls{spar}, making it reusable in any OpenFHE project that needs RGSW products. The \clientlib{} and \serverlib{} consume the \corelib{} library through an abstract interface.
