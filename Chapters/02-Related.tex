\chapter{Related Works} % ? The sPAR Protocol
\label{chp:protocol}

This section details the fundamental building blocks of the \gls{spar} protocol, and the protocol itself. To achieve a reasonable depth the protocol utilizes the \textit{external product}, a primitive from TFHE bootstrapping that allows homomorphic multiplication of binary digits with near-constant noise bounds --- enabling a large number of binary multiplication without consuming a level/bootstrapping. This primitive was ported to BGV-RNS for this thesis, which does not natively allow digit decomposition as normally used by the external product.
