\section{Performance Benchmarks}
The benchmarks were run on an AMD Ryzen 5 5600X CPU (6-core{@}3.7GHz) with 32Gb RAM in WSL2 Ubuntu 24.04 LTS Linux with the parameters listed in~\autoref{tab:bench:params}.
%% TODO: Move compiler information elsewhere or include compiler and version!
OpenFHE version 1.5.1 and the code is compiled using GCC v16.1 with all available compiler optimizations, including \texttt{-O3} and \texttt{-march=native}, except for the AVX512 instruction set (see~\autoref{avx512}). All benchmarks were repeated 10 times and the mean times were recorded and presented in the tables below. Coefficient of variation was strictly below $2.5\%$ for all the runs.
