\section{Performance Benchmarks}
\label{sec:results:benchmarks}
The benchmarks were run on an AMD Ryzen 5 5600X CPU (6-core{@}3.7GHz) with 32Gb RAM in WSL2 Ubuntu 24.04 LTS Linux with the parameters listed in~\autoref{tab:bench:params}.
OpenFHE version 1.5.1 and the code is compiled using GCC v16.1 with all available compiler optimizations, including \texttt{-O3} and \texttt{-march=native}, except for the AVX512 instruction set as the testing hardware does not support it.

\vspace{4pt}
\subsection{Core Library}
We present the measured benchmarks in \cref{tab:bench:rgsw} and extrapolate numbers for $T=k\ell=14$ using the method described in \cref{sec:amdahl}. The fitted parameters and resulting estimates are listed in \cref{tab:bench:amdahl}. All three fits give $R^2 \geq 0.9975$. We emphasize that the slower runtime at $T=6$ compared to $T=5$ is expected due to the complete hardware saturation effect also discussed in \cref{sec:amdahl}, and is especially pronounced here due to short test time on the order of tens of milliseconds.

Each function in~\cref{tab:bench:full} except \Call{Server::Decrypt}{} is invoked once \emph{per client} every round. The client functions would in practice run in perfect parallel, as each user encrypts and partially decrypts independently. The server decryption is relatively fast. The total runtime is then clearly dominated by the $\eta$ \serverWrite{} calls per round. The algorithm runs the inner loop $9\eta$ times, yielding an asymptotic runtime of $\mathcal{O}(\eta^2)$ per full round.
